Platform Capabilities

Key Security & Verification Signals

📱

Dynamic QR Sessions

Cryptographically unique, time-limited QR tokens regenerated per session to eliminate static screenshot sharing among students.

👤

Biometric Face Match

ArcFace neural network embedding match confirming physical identity of the enrolled student with high confidence.

🔑

Device Fingerprinting

Privacy-preserving SHA-256 hardware hash validation binding attendance submissions to trusted mobile devices.

📍

Geolocation Radius Check

GPS coordinates and Haversine distance validation verifying student physical presence within designated classroom bounds.

🧠

Isolation Forest Anomaly ML

Machine Learning anomaly detection algorithm calculating risk scores to flag suspicious proxy attempts in real time.

🏛️

Role-Based Workspaces

Tailored access controls for Institutional Administrators, Course Faculty, and Enrolled Students.

Verification Pipeline

5-Step Attendance Verification Flow

01
Faculty Launch
Instructor creates active session & generates dynamic QR code.
02
Student Scan
Authenticated student scans active session QR token via mobile web app.
03
Biometric & GPS
Face embedding match & GPS classroom radius check execute concurrently.
04
Device & AI Risk
Hardware fingerprint & Isolation Forest ML model evaluate multi-signal vector.
05
Final Decision
Attendance recorded as PRESENT or flagged in real-time Fraud Log.

About the Project

The Smart Attendance Fraud Detection Platform is a complete microservice-based institutional solution engineered to eliminate attendance proxies and biometric fraud.

Java Spring Boot Suite

Eureka Server, API Gateway, Auth, Faculty, Student, Attendance, Face, Device, Location, and Fraud microservices.

Python FastAPI & ML

Isolation Forest anomaly detection model evaluating multi-signal attendance vectors in real time.

React 18 & Vite Frontend

Modern, responsive workspace dashboards for Administrators, Faculty, and Students.
